# OpenSpec 协作约定（AGENTS）

## 工作流
- 必须遵循四阶段：Draft Proposal -> Review & Align -> Implement Tasks -> Archive。
- 未获用户批准，不得进入实现阶段。

## 实施约定
- 严格按 `openspec/changes/<change>/tasks.md` 顺序执行。
- 每完成一个任务：
  1) 更新代码/文档
  2) 执行该任务验证步骤
  3) 记录验证结果
  4) 创建一次独立 commit

## 默认决策矩阵
- 安全/数据：优先保守方案。
- 兼容性：默认向后兼容。
- 错误处理：显式失败，避免静默。
- 重试策略：有限重试 + 退避。

## 质量门槛
- 架构改造任务必须至少覆盖关键路径测试。
- 若出现阻断级问题（安全、数据一致性、不可回滚），立即停在 Review 阶段。
