# 项目级规范（OpenSpec）

## 项目目标与边界
- 项目：overleaves跨平台论文写作agent工具
- 目标：仿照olcli拉取overleaf项目的内容，通过agent功能协助用户进行论文写作、内容修改、格式调整等操作，最终将修改结果推送回overleaf项目
- 边界：使用python作为基本开发语言，使用Flet开发python的GUI，调用远程LLM的API进行论文写作和更改
