## 实现策略/步骤

1. 首先，现在每次打开软件后都需要手动再次拉取项目文件，但实际上，本地其实缓存了远程项目。所以现在请为软件增加多项目管理功能，左上角新增项目菜单栏，下拉菜单可以选择打开已有项目或者创建新项目。对于创建新项目，填入cookie和项目编号放在创建新项目的选项中，cookie可以从本地缓存中预先填入，方便如果是同一个人使用就不用修改，LLM相关的设置仍然放在设置中。对于打开已有项目，列表选择本地缓存项目，而且打开后如果本地已经缓存了项目文件，自动加载本地缓存，而不用再手动再次拉取项目。
2. 现在主要页面的三栏宽度都是固定的，请修改为可以直接通过鼠标拖拉三栏的宽度，并且可以点击按钮隐藏和显示左栏文件树和右栏pdf预览。
3. 现在中间栏目如果tex文件，请从只读修改为可修改，并且和拉取项目文件一样，新增一个菜单栏，可以推送修改后的文件到网页。
4. 我发现现在点击左栏文件树的文件后，整个页面都重新渲染了，其实可以只重新渲染中间栏。
